
# MOCHIÉ 🍡

MOCHIÉ adalah aplikasi Flutter yang dibuat untuk project mata kuliah Pemrograman Berbasis Platform (PBP).

Aplikasi ini digunakan untuk melihat katalog dan melakukan pemesanan mochi. Pengguna bisa melihat berbagai pilihan mochi, mencari produk, melihat detail produk, menambahkan produk ke favorite dan cart, melakukan checkout, serta melihat riwayat pesanan.

## Fitur

- Login
- Melihat daftar mochi
- Mencari mochi
- Filter dan sorting produk
- Melihat detail mochi
- Favorite
- Cart
- Checkout
- Riwayat pesanan
- About Me
- Mengganti foto profil

## Teknologi

- Flutter
- Dart
- Material Design
- Image Picker
